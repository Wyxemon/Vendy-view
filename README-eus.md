##  Instalación y ejecución

```bash
# 1. Klonatu repositorioa
git clone https://github.com/Wyxemon/Vendy-view

# 2. Sartu proiektuaren karpetan
cd Vendy-view

# 3. Instalatu mendekotasunak
npm install

# 4. Hasi garapen zerbitzaria
npm run dev
```

##  Tecnologías

- **React** —> Erabiltzaile-interfazeen liburutegia
- **Vite** —> Bundler eta garapen zerbitzaria
- **Firebase** -> Backend-a eta denbora errealeko datu-basea
